# Foto profil

Taruh foto profil di folder ini dengan nama **`profil.jpg`**.

Foto otomatis dipotong dan memenuhi bingkai foto di kartu (`BoxFit.cover`),
jadi tidak perlu mengatur ukuran atau rasio terlebih dahulu.

- Format yang disarankan: JPG.
- Gunakan foto potret, misalnya 640×800 piksel atau lebih, agar hasilnya tajam.
- Setelah menambah atau mengganti foto, hentikan lalu jalankan ulang aplikasi
  (`flutter run`). Hot reload tidak memuat aset baru.
- Selama foto belum ada, kartu menampilkan inisial nama.
